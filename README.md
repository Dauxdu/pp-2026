# pp-2026

**Параллельный аудит парольных хешей на синтетических данных** — инструмент для высокопроизводительного анализа и тестирования стойкости хешей.

---

## Подготовка и установка

Перед началом работы убедитесь, что у вас установлен Python 3.10+ и утилита `make`.

### 1. Создание и активация виртуального окружения

**Для Linux / macOS:**

```bash
python -m venv .venv
source .venv/bin/activate
```

**Для Windows (PowerShell):**

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### 2. Установка зависимостей

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Деактивация окружения (по окончании работы)

```bash
deactivate
```

---

## Запуск и использование

Управление проектом автоматизировано с помощью `Makefile`.

### Пошаговый запуск:

1. **Генерация синтетических данных:**
   ```bash
   make generate_data
   ```
2. **Запуск аудита (выберите масштаб):**
   ```bash
   make start_small   # Быстрый тест на малом объеме
   make start_medium  # Средний объем данных
   make start_large   # Нагрузочный тест
   make start_all     # Последовательный запуск всех тестов
   ```
3. **Визуализация результатов:**
   ```bash
   make generate_plots
   ```

### Доступные команды

Чтобы увидеть полный список доступных команд и их описание, выполните:

```bash
make help
```
